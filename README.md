Данный проект представляет собой серверную часть (REST API) на Spring Boot с системой аутентификации через JWT и клиентским приложением.
JWT – Аутентификация и авторизация пользователей
Spring Security – Настройка прав доступа (роли: USER, ADMIN, STAFF)
Шифрование паролей – BCryptPasswordEncoder
Защита от CSRF и CORS – Настроены безопасные HTTP-заголовки


Приложение будет доступно по адресу:
http://localhost:7655
